# Brolli-Glass

_A macOS-style desktop for Hyprland, with liquid glass drawn by a Hyprland plugin._

![The desktop](screenshots/desktop.png)

A slim menubar, widgets on the wallpaper, a magnifying dock and Spotlight — all
sitting on glass that the compositor renders under them, not a blurred
screenshot taken by the shell.

Built in [Quickshell](https://quickshell.outfoxxed.me/)/QML on top of
[end-4 / illogical-impulse](https://github.com/end-4/dots-hyprland).
